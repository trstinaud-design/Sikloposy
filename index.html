⚙️ Paramètres généraux

🔒 Code PIN de déverrouillage rapide

Ouvrez l'application par un code à 4 chiffres au lieu de retaper votre e-mail et votre mot de passe.

💾 Sauvegarde & restauration

Vos données vivent dans ce navigateur. Un fichier rangé ailleurs est votre seule protection réelle contre une perte du téléphone.

Sur téléphone, « Sauvegarder par e-mail » ouvre le menu de partage : choisissez Gmail, WhatsApp ou Drive. Sur ordinateur, le fichier est enregistré puis votre logiciel de messagerie s'ouvre — il ne reste qu'à joindre le fichier.

☁️ Synchronisation en ligne

Sauvegarde automatique sur un serveur, sans limite de taille, et accès depuis plusieurs appareils. Facultatif : sans cela, l'application continue de fonctionner entièrement hors ligne. Voir le README pour créer le projet gratuit (5 min).

Données d'un ancien compte local détectées sur cet appareil. Voulez-vous les reprendre dans ce compte en ligne ?

🛟 Copie de secours interne

Une copie est conservée séparément dans l'appareil à chaque enregistrement. Elle protège d'une corruption des données, pas d'un effacement du navigateur.
